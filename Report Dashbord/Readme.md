# Dashbord pipeline

1. Running main.py launch a webbrowser interface , the  user is requested to import the main pipeline output files
 
2. Otherwise, there is a Demonstration option.  Which if selected will download 500 .pdb files from alphafold and it will also generate simulation of output files from kraken2, esmfold and seqscreen.

3. The data will be then used to create text summary and stat charts 

4. The data is also summarized in table 

5. All data is displayed in dashbord + download option

6. You can select the seq identied from a list to do Structural prediction using chimera. It will first install it then run it.



# How-to-Run

1. Download this folder

2. Download ChimeraX-1.12.exe from https://www.cgl.ucsf.edu/chimerax/download.html
   
3. Put ChimeraX-1.12.exe  in downloaded folder and set it as cd
   
4. Run main.py
