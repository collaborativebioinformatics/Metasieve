# Dashbord pipeline

1. Running main.py launch a webbrowser interface , use is asked to import the main pipeline output files
 
2. Otherwise there is a Demonstration option.  Which if selected will download 500 .pdb files from alphafold and it will also generate simulation of output files from kraken2, esmfold and seqscreen.

3. The data will be then use to create text summary but also some charts. 
I don't know which info would be valuable or not just just putted simple 4 charts , I would need your feedback and suggestions on which info worth showing

4. The data also summarized in table 

5. All displayed in dashbord + download option

6. You can select the seq identied from a list to do Structural prediction using chimera
For that it will first install it then run it.



# How-to-Run

1. Download this folder

2. Download ChimeraX-1.12.exe from https://www.cgl.ucsf.edu/chimerax/download.html
   
3. Put ChimeraX-1.12.exe  in downloaded folder and set it as cd
   
4. Run main.py
